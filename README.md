# DRIVE v3 (.NET 8 WPF) — Автоматизированная система управления автосалоном

Современное настольное приложение на платформе **C# / WPF (.NET 8)** с базой данных **SQLite**, разработанное взамен устаревшей версии на Python (Tkinter).

---

## 🚀 Основные возможности и преимущества

### 1. 🎨 Премиальный пользовательский интерфейс (UI/UX)
- **Современная тёмная тема** в глубоких тонах (`#0b1120`, `#0f172a`, `#172033`) с цветными светящимися индикаторами статусов и плавными переходами.
- **Два режима отображения каталога автомобилей**:
  - **Сетка карточек (Card/Tile View)**: фото авто, цветные статус-бейджи, чипсы комплектации (л.с., КПП, привод, пробег), крупная цена и кнопки быстрых действий прямо на карточке («Сделка», «Бронь», «Изменить»).
  - **Классическая таблица (DataGrid)**: со всеми характеристиками, выравниванием, цветными метками статусов и двойным кликом для редактирования.
- **Фотографии автомобилей**: встроенные графические превью и возможность загрузить любое фото с компьютера через проводник (копируется в `Assets/Cars/`).
- **Тонкие современные скроллбары** и векторные SVG/Path иконки.

### 2. 🔍 Фильтрация и поиск во ВСЕХ таблицах
- **Автомобили**:
  - Живой мгновенный поиск по марке, модели, VIN-номеру, типу кузова, двигателю и КПП.
  - Фильтр по статусу («В наличии», «Забронирован», «Продан», «На диагностике», «На ремонте»).
  - Динамический фильтр по марке (автоматически формирует список брендов из БД).
  - Сортировка: по умолчанию, по возрастанию/убыванию цены, по новизне года выпуска, по минимальному пробегу.
  - Кнопка сброса фильтров в один клик.
- **Клиенты**: мгновенный поиск по ФИО, номеру телефона, email и комментариям.
- **Продажи**: поиск по авто/покупателю/менеджеру, фильтр по способам оплаты («Наличные», «Карта», «Перевод», «Кредит») с автоматическим подсчетом суммы отфильтрованных сделок.
- **Бронирования**: поиск по авто и клиентам, подсветка истекших броней («Истекла» / «Активна»).
- **Поставщики**: поиск по названию компании, контакту, телефону и адресу.
- **Журнал операций**: поиск по тексту выполненных действий и авто.

### 3. 📊 Экспорт отчётов в Excel (.xlsx) и печать в PDF/HTML
- **Генеральный финансовый отчёт (.xlsx)**:
  - Формируется через официальную библиотеку **ClosedXML** (работает автономно, наличие установленного MS Office не требуется!).
  - Включает титульную шапку автосалона, сводку ключевых показателей, долю брендов, журнал продаж с формулами суммы `=SUM(...)`.
- **Прайс-лист автомобилей (.xlsx)**: форматированные столбцы, цены в рублях, подсчет итоговой стоимости склада.
- **Журнал продаж в Excel (.xlsx)**: реестр сделок с форматированием.
- **База клиентов в Excel (.xlsx)**.
- **Печать договора купли-продажи / чека сделки (PDF / HTML)**:
  - Генерация официального договора купли-продажи с реквизитами автосалона ООО «Драйв Моторс», данными покупателя, характеристиками авто, суммами и местами для подписи/печати.
  - Кнопка «🖨 Печать / Сохранить в PDF» открывает системное окно печати Windows / браузер.
- **Сводный управленческий отчет для руководства** с KPI-метриками и структурой выручки.

### 4. ⚡ «Ништяки» и исправление багов версии Python
- **Устранение багов**:
  - В Python-версии при оформлении продажи/брони брался индекс выпадающего списка `cb.current()`, что вызывало критические ошибки при несовпадении порядка записей. В C# выбор привязан строго к объектам и ID.
  - Добавлена полная валидация сроков бронирования (нельзя поставить дату в прошлом).
  - Реализована функция **«Оформить в продажу» в 1 клик** прямо из раздела бронирований.
  - Реализовано безопасное **снятие брони** (автомобиль автоматически возвращается в статус «В наличии»).
  - Добавлены полноценные операции **Редактирования и Удаления** для автомобилей, клиентов и поставщиков (в Python их не было вовсе!).
  - Реализован аудит: каждое действие (добавление, редактирование, статус, продажа, бронь, удаление) автоматически пишется в журнал с точным временем.
- **Резервное копирование БД**:
  - Кнопки **«💾 Бэкап БД»** и **«📥 Восстановить»** прямо в шапке приложения.
- **Разграничение ролей пользователей**:
  - **Администратор (admin)**: полный доступ + вкладка управления сотрудниками (добавление, смена паролей, удаление).
  - **Директор (director)**: полный аналитический доступ, финансовые отчеты и экспорт.
  - **Менеджер (manager)**: работа с каталогом, оформление продаж, бронирование, база клиентов.
  - Кнопки быстрого 1-клик входа на окне авторизации для быстрой демонстрации преподавателю.

## 🛠 Запуск и сборка проекта

### Требования
- Установленный **.NET 8 SDK** (или выше: .NET 9 / 10).
- Windows 10 / 11.
- Visual Studio 2022 (или VS Code / Rider).

### Запуск через консоль:
```powershell
cd c:\Users\Аркадий\Desktop\FDNJ_CSharp
dotnet run
```

### Открытие в Visual Studio:
Откройте файл проекта `FDNJ_CSharp.csproj` в Visual Studio 2022 и нажмите клавишу **F5**.
